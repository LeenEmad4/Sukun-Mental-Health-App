# Sukun – Mental Health Support App

Sukun is a mobile application designed to provide accessible mental health support in Jordan. It connects users with mental health professionals through online therapy sessions and offers AI-powered chatbot support.

## Technologies
- Flutter & Dart
- Supabase & PostgreSQL
- OpenAI API
- LiveKit
- Firebase Cloud Messaging

## Features
- AI-powered chatbot
- Online therapy sessions
- Therapist browsing and appointment booking
- Secure messaging and video calls
- Anonymous user profiles
- Arabic and English support
